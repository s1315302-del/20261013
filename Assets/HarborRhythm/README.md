# 港都・音浪駕駛

建築與背景更新：倉庫加入程序式風化磚牆、窗框／窗台、捲門、排水管與金屬屋頂接縫；音樂中心加入金屬蜂巢邊框、玻璃入口及階梯。背景加入大氣天空、山稜線、城市高樓、港灣船隻、货櫃、吊車桁架、植栽與街燈。素材在本機生成，無需下載外部模型。原油門節奏玩法保持不變。

開啟 `Assets/Scenes/KaohsiungHarbor.unity`，按 Unity Play，再按 Enter 或「開始演出」。

- W／↑／空白鍵：加深油門；S／↓：放鬆油門。放開按鍵會保持目前深度。
- 畫面左下的滑桿可直接設定油門；手把 RT 支援類比輸入，LT 可降低輸入。
- 油門 0–100% 對應音浪高度 1.4–6.4 公尺。
- 球沿 3D 軌跡落向青綠色接球環；抵達接球平面的瞬間判定高度差。
- 高度差 ≤0.32m：PERFECT；≤0.72m：GOOD；其他：MISS。
- 100 BPM、64 顆球的固定譜面；音效由程式合成，不需下載音樂素材。
- ESC：暫停／繼續；R：重新開始。完成後顯示分數、準確率與最高連擊。

場景包含風格化蜂巢立面、駁二倉庫／藝術裝置、舊港鐵道、貨櫃吊車、夕陽與水面。這是原創幾何風格原型，非建築實測還原。車輛作為油門操控視覺主體；本關卡是定點演奏，不含行車導航。

場景參數可在 `Harbor rhythm controller` 的 Inspector 調整：BPM、球數、接近時間及高度範圍。Auto Pilot 是驗證用途，正常遊玩請保持關閉。

若場景尚未生成，等待 Unity 編譯完成後，使用選單 `Harbor Rhythm > Build Kaohsiung 3D Scene`。建置會建立／更新獨立場景並排在 Build Settings 第一個，不覆蓋 SampleScene。產生的 `HarborPreview.png` 是 3D 場景預覽，遊戲 HUD 由執行時繪製。
